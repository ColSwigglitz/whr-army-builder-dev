# WHR Army Builder branding assets

Place the new branding files in this structure:

```text
assets/
└── branding/
    ├── whr-logo-full.webp
    ├── whr-emblem.webp
    └── icons/
        ├── whr-icon-512.png
        ├── whr-icon-192.png
        ├── favicon-32.png
        └── favicon.ico
```

## Usage

- `whr-logo-full.webp` — full Warhammer Renaissance Army Builder lockup for the landing page and large branding areas.
- `whr-emblem.webp` — shield/emblem for the builder header and Roster Pad.
- `icons/whr-icon-512.png` — large application/PWA icon.
- `icons/whr-icon-192.png` — small application/PWA icon.
- `icons/favicon-32.png` — 32px browser icon.
- `icons/favicon.ico` — multi-size browser favicon.
